# Εννέα Χέρια

Σχεδιαστική δουλειά για σόλο χαρτοπαίγνια με βάση το πόκερ και climbing μηχανική,
συν ένα playable prototype.

## RAISE — το prototype

Ιεραρχία χεριών πόκερ παιγμένη ως climbing σκάλα. Δεκαπέντε φύλλα, οκτώ antes,
seeded RNG, κατάστημα ανάμεσα στους γύρους. Σχεδιασμένο για κινητό, με ένα χέρι.
UI στα αγγλικά.

### Κανόνες

- **Pair** 10 · **Trips** 25 · **Straight** 40 · **Flush** 60 · **Full House** 80 · **Quads** 120
- Κάθε χέρι πρέπει να ξεπερνά το προηγούμενο (**Rung**): ανώτερη κατηγορία, ή ίδια
  κατηγορία με ψηλότερη αξία.
- Σκορ = βάση × **Chain** (θέση στην αλυσίδα). **Pass** μηδενίζει Rung και Chain και
  κοστίζει ένα **Breath**. Άδειασμα χεριού: +50%.
- **Ace in the Hole:** παίζεις έναν Άσο μόνο του → το Rung μηδενίζει, η Chain
  **μένει**, μηδέν πόντοι. Ένα Step Down που βρίσκεις στην τράπουλα.
- Ξεκινάς με μία **Chisel** (αλλάζεις την αξία ενός φύλλου). Straight flush μετράει
  ως Flush. Ο άσος είναι μόνο ψηλός.

### Ενισχυμένα φύλλα (κατάστημα)

| | Εφέ | Κόστος |
| --- | --- | --- |
| **Gold** | Βάση ×2 όταν παίζεται | 6 |
| **Glass** | Βάση ×3, σπάει μετά από μία χρήση | 5 |
| **Wild** | Οποιαδήποτε αξία και χρώμα· μετράει και ως Άσος | 9 |
| **Steel** | Μοιράζεται σε κάθε χέρι | 8 |

Το κατάστημα προσφέρει 3 αναβαθμίσεις + 2 φύλλα ανά ante. Τα φύλλα μπαίνουν στην
τράπουλα μόνιμα· η τράπουλα είναι το build.

### Challenges

Στα antes 3 και 6 ισχύει ένα twist, διαφορετικό ανά run (seeded), με στόχο ×0,85:
**No Pass** · **Short Hand** (14 φύλλα) · **Blind Deal** (7 φύλλα ανάποδα ως το πρώτο
παίξιμο) · **High Ground** (Rung ξεκινά από Pair 10) · **One Breath** · **Thin Air**
(Chain ≤ ×4) · **Rich Air** (στόχος ×1,15, αμοιβή ×2). Το επόμενο challenge
προαναγγέλλεται στο κατάστημα, ώστε να αγοράσεις αναλόγως.

Το «Pairs Pay Nothing» δοκιμάστηκε και κόπηκε: σκότωνε 48–85% των runs ακόμα και
στο μισό — τα ζεύγη είναι τα σκαλιά της σκάλας, όχι προαιρετικό build.

### Δομή

| Αρχείο | Ρόλος |
| --- | --- |
| `site/raise/game.js` | Καθαρή λογική, χωρίς DOM. Τρέχει σε browser (`window.RAISE`) και σε Node. |
| `site/raise/ui.js` | DOM, είσοδος (tap, swipe), sheets, αποθήκευση run σε `localStorage`. |
| `site/raise/fx.js` | Σωματίδια, **ήχος** (Web Audio synth, χωρίς αρχεία), FLIP animation, δόνηση. |

| `tools/sweep.js` | Σάρωση δυσκολίας, με θανάτους ανά challenge. |
| `tools/bundle.py` | Ενώνει τον φάκελο σε ένα αρχείο για artifact. |

### Βαθμονόμηση

Όλα από το `tools/sweep.js`, με άπληστο bot που χρησιμοποιεί Chisel και Άσους:
στόχοι `100 → 1500`, αμοιβή `12 + πλεόνασμα/60`, challenge στόχος ×0,85.
Αποτέλεσμα: ~14% νίκες bot, θάνατοι ανά ante `0 / 30 / 56 / 78 / 50 / 52 / 41 / 37`
— κανένας γκρεμός — και κάθε challenge σκοτώνει 9–30% όταν εμφανίζεται.
Το πρώτο χέρι κάθε run ξαναμοιράζεται μέχρι να καθαρίζει με απλό παίξιμο.

Το run αποθηκεύεται μετά από κάθε κίνηση. Ο ήχος κλείνει από το μενού.

## Δημοσίευση

Το `.github/workflows/pages.yml` ανεβάζει τον φάκελο `site/` στο GitHub Pages.

Απαιτείται **μία χειροκίνητη ενέργεια, μία φορά**, από κάποιον με δικαιώματα
admin στο repository:

> **Settings → Pages → Build and deployment → Source: GitHub Actions**

Δεν γίνεται από το workflow. Το `actions/configure-pages` έχει παράμετρο
`enablement: true` που υποτίθεται ότι δημιουργεί το Pages site μέσω API, αλλά
η δημιουργία απαιτεί δικαιώματα admin στο repository — το `GITHUB_TOKEN` ενός
workflow απαντά `Resource not accessible by integration`. Δοκιμασμένο, δεν
δουλεύει.

Μετά την ενεργοποίηση, κάθε push που αγγίζει το `site/` κάνει redeploy, ή
τρέχεις το workflow χειροκίνητα από την καρτέλα Actions.

Διεύθυνση μετά την ενεργοποίηση: **https://ndimt.github.io/game/**

## Νομικές σημειώσεις

Το πόκερ και το cribbage είναι δημόσιο κτήμα. Οι μηχανισμοί των climbing games
(Big Two, Zheng Shangyou) είναι επίσης δημόσιο κτήμα, αλλά τα ονόματα, οι ειδικές
κάρτες και τα εικαστικά των εμπορικών εκδόσεων προστατεύονται — γι' αυτό όλη η
ορολογία εδώ είναι πρωτότυπη.
